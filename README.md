# 🗄️ Altron SQL: Production-Grade Text-to-SQL

[![CI](https://github.com/Kedar36rgb/altron-sql/actions/workflows/ci.yml/badge.svg)](https://github.com/Kedar36rgb/altron-sql/actions/workflows/ci.yml)

**Live Demo:** [https://altron-sql.streamlit.app/](https://altron-sql.streamlit.app/)

A secure, self-healing Text-to-SQL application. Upload a CSV, ask a question in plain English, and get a validated, read-only SQL query, a data table, and an auto-generated chart.
